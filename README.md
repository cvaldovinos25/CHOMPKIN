# CHOMPKIN
*La noche de dulces.* Introducción en realidad aumentada para un juego de Halloween (solo video interactivo, sin partida), hecho con HTML, CSS y JavaScript (sin servidor).

## Cómo funciona
1. La cámara se abre como fondo.
2. Apunta a un punto fijo (piso o pared) y toca **ANCLAR AQUÍ**: el laberinto queda fijo en ese punto del mundo (seguimiento visual del fondo).
3. Las personas con **disfraz amarillo** que entren al laberinto controlan a la calabaza: se detectan por color. Se comen los dulces y esquivan a los murciélagos.
4. Pastillas grandes = poder temporal para comer murciélagos. 3 vidas, niveles crecientes, música chiptune original.

## Consejos
- Buena luz y amarillo liso; evita fondos amarillos.
- No ancles sobre el disfraz: ancla a una pared o al piso.
- Sin personas amarillas, una calabaza demo juega sola.
- No se guarda ni envía ninguna imagen.

## Publicar en GitHub Pages
1. Crea un repositorio (ej. `CHOMPKIN`) y sube todo el contenido.
2. Settings > Pages > Deploy from a branch > `main` / root.
3. Abre `https://TU-USUARIO.github.io/CHOMPKIN/` en el celular (HTTPS es obligatorio para la cámara).

Las fuentes vienen de Google Fonts (requiere conexión la primera vez). Personajes, laberinto y música son originales.
